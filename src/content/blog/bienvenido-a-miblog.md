# Bienvenido a MiBlog

Este es el primer post del blog. El sitio está construido con **Astro** y el
contenido se administra con **Decap CMS**.

## ¿Cómo crear nuevos posts?

Puedes entrar a `/admin/` y crear contenido desde la interfaz, o escribir un
archivo Markdown directamente en `src/content/blog/`.

## Frontmatter

Cada post usa este frontmatter:

```yaml
---
title: "Título del post"
description: "Breve descripción."
pubDate: 2026-08-01
author: "Autor"
tags: ["etiqueta"]
---
```
